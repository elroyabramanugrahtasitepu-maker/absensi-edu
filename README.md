# Absensi Edu

A web-based employee attendance and activity monitoring system developed to manage employee attendance records and daily activities.

## Overview

Absensi Edu is a web application designed to help organizations manage employee attendance and activity records through a centralized web-based system.

The system allows administrators to monitor employee activity, view attendance history, and organize employees based on their departments or roles.

## Features

- Employee attendance management
- Employee and staff data management
- Department and role categorization
- Employee activity recording
- Attendance history
- Activity monitoring
- Time and location recording
- Employee-based activity filtering
- Administrative dashboard
- MySQL database integration
- Responsive web interface

## Technologies

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Tailwind CSS

## System Overview

The system provides an interface for monitoring employee activities and attendance.

Employees can be organized into different departments or roles, such as:

- IT
- Finance
- Staff
- Marketing
- Other departments

Attendance and activity records can be displayed based on the selected employee.
